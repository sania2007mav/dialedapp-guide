# DialedApp — руководство

Веб-приложение для работы с **1С:Управление торговым предприятием** (ИП Dialed / ТОО «Диалайт»).

- **Приложение:** https://dialed.melnichuk.kz/
- **Руководство (GitHub Pages):** https://sania2007mav.github.io/dialedapp-guide/
- **Репозиторий гайда:** https://github.com/sania2007mav/dialedapp-guide

## Документы

| Файл | Содержание |
|------|------------|
| [index.html](index.html) | Описание, инструкция, интерактивный чек-лист |
| [USER-CHECKLIST.md](USER-CHECKLIST.md) | Чек-лист для печати / отправки |

## Разделы приложения

1. **Обзор** — KPI остатков, диаграммы, избранное, алерты  
2. **Дашборды** — выручка, топы, ABC, дебиторка, склад; **выбор года и месяца**  
3. **Номенклатура** — каталог, цены, остатки, штрихкод  
4. **Заказы** — история заказов покупателя  
5. **Заказ** — корзина и создание документа в 1С  

## О базе

OData: `go1c.kz` · конфигурация **УТП** (контрагенты, заказ покупателя, товары на складах, регистр продаж).
